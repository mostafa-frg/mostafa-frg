# Cybersecurity Labs

Practical security projects covering network security, web security, and SOC analysis.

## Structure

- [Network Security Lab](network-security-lab/) — authorized TCP service inventory and reporting.
- [Web Security Lab](web-security-lab/) — local web-security concepts and secure coding.
- [SOC Log Analyzer](soc-log-analyzer/) — SSH authentication log analysis and detection.

All labs are intended for systems and environments where you have explicit authorization.

## Approach

The projects focus on understanding systems, reproducing security issues in controlled environments, and documenting defensive fixes.

More labs will be added as they are built.
