# Active Directory Security Lab

A controlled Windows-domain lab for learning identity security and common enterprise attack paths without touching real environments.

## Lab areas

- Domain enumeration concepts
- Kerberos and NTLM fundamentals
- Password-policy review
- Group and privilege auditing
- Service-account exposure
- Windows event-log investigation
- Hardening recommendations

## Deliverables

- Enumeration checklist
- Detection notes
- Hardening checklist
- Evidence collection guide

Build this only in an isolated lab you own or are authorized to assess.
