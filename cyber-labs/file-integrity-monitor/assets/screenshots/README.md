# Screenshots

Store verified screenshots captured from real CLI execution here.

## Naming
- `01-init-clean.png` — successful snapshot initialization
- `02-change-detected.png` — changed/added/deleted file detection
- `03-hmac-tamper.png` — snapshot tamper detection
- `04-check-clean.png` — clean verification run

## Format
- PNG preferred
- 1600x900 or 1920x1080 preferred
- Crop only irrelevant desktop UI; do not alter command output
- Never include secrets, tokens, private paths, or personal data

## README usage
Use the strongest screenshot as `assets/screenshots/01-init-clean.png` and reference it from the project README.
