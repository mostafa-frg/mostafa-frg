# Screenshots

Store verified screenshots captured from real CLI execution here.

## Naming
- `01-input-log.png` — representative raw log input
- `02-normalized-output.png` — normalized JSON/JSONL output
- `03-mixed-input.png` — multiple supported input formats
- `04-error-handling.png` — invalid/malformed input handling
- `05-detection-pipeline.png` — normalized records flowing into detection alerts

## Format
- PNG preferred
- 1600x900 or 1920x1080 preferred
- Crop only irrelevant desktop UI; do not alter command output
- Never include secrets, tokens, private paths, or personal data

## README usage
Use the strongest normalization screenshot as `assets/screenshots/01-input-log.png` and reference it from the project README.
