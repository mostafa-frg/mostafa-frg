# Mosta Terminal

A Linux/Termux command launcher for the network and security labs in this repository.

The prompt starts with **Mosta** and every command has a short alias:
- mnet — network diagnostics
- mdns — DNS checks
- mhttp — HTTP security audit
- mpcap — offline PCAP analysis
- msoc — log analysis
- mconf — network config audit
- mroute — route analysis
- mtriage — incident triage

The launcher is for owned systems, supplied evidence, and isolated labs.
