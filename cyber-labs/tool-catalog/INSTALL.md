# Installation

This directory is a reference catalog; it does not bundle or silently install external security tools.

For optional Linux desktop command aliases, use the repository's Linux CLI layer:

    cd ../mosta-terminal
    ./install.sh

Then inspect what is actually available:

    mosta-tools
    mosta-doctor

Install third-party tools through the package manager or official distribution channel for your Linux distribution. Review upstream licensing and permissions before use.
