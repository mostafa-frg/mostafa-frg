# Web Security Lab

A local training lab for understanding common web-security failures and their mitigations.

## Topics

- Input validation
- Output encoding
- Authentication boundaries
- SQL injection concepts
- Cross-site scripting concepts
- Secure vs insecure implementation patterns
- Security testing methodology

The lab is designed to run locally. Do not expose intentionally vulnerable endpoints to the public internet.

## Suggested workflow

1. Run the application locally.
2. Read the implementation.
3. Reproduce the issue only against the local lab.
4. Apply the secure implementation.
5. Run the included tests.
