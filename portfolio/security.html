PRIVACY · SECURITY · RESPONSIBLE USE

Know what runs
and where.

MOSTA is designed to minimize data collection. Local utilities process selected files and text in your browser. Network tests and external lookups send the necessary requests to their stated providers.

LOCAL PROCESSING

Files & pasted text

SHA-256 and HMAC hashing, JSON and XML formatting, CSV conversion, regex testing, password utilities, JWT decoding, URL/Base64 conversion, Linux configuration checks and pasted HTTP/CSP analysis run in the browser. Selected files and pasted content are not uploaded to the MOSTA API by these local tools.

EXTERNAL SERVICES

Network measurements

Speed and HTTPS latency tests send test traffic to speed.cloudflare.com. DNS queries go to cloudflare-dns.com; public IP requests go to api.ipify.org; MAC vendor lookups go to api.macvendors.com; certificate transparency searches go to crt.sh. These providers receive the relevant query or test traffic. Avoid private or sensitive inputs.

BROWSER LIMITS

Network access restrictions

A standard browser cannot perform raw ICMP ping, packet capture, traceroute, or unrestricted TCP scanning. MOSTA uses browser-compatible HTTPS diagnostics and does not represent them as equivalent to low-level network tools.

RESPONSIBLE TESTING

Authorized systems only

Run diagnostics only against networks, devices, and services you own or have explicit permission to test. Do not submit confidential configuration, credentials, private IP plans, or other sensitive information to external lookup providers.

WORKSPACE

Account security

The private workspace uses server-side authentication, secure session cookies, role checks, and audit events. Workspace availability depends on the separately hosted Cloudflare Worker and its configured database and secrets.

REPORTING

Found an issue?

Review the source code and report reproducible bugs or security concerns through the project repository. Do not publish credentials, session tokens, or exploitable personal data in a public issue.
