PRIVACY · SECURITY · RESPONSIBLE USE

Know what runs
and where.

MOSTA tools are designed to minimize data collection. Local utilities process selected files and text in your browser. Network tests and external lookups necessarily send requests to their stated providers.

LOCAL PROCESSING

Files & pasted text

SHA-256 hashing, JSON formatting, regex testing, password generation, URL conversion and pasted configuration/header checks run locally. Selected file contents and pasted text are not sent to MOSTA servers.

EXTERNAL SERVICES

Network measurements

Speed tests send test traffic to Cloudflare. DNS, public IP, MAC vendor and certificate-transparency lookups send the necessary query to their named provider. Avoid private or sensitive inputs.

BROWSER LIMITS

Network access restrictions

A standard browser cannot perform raw ICMP ping, packet capture, traceroute or unrestricted TCP scanning. MOSTA uses browser-compatible HTTPS diagnostics and does not pretend they are equivalent.

RESPONSIBLE TESTING

Authorized systems only

Only run diagnostics against networks, devices and services you own or have explicit permission to test. Tools are not intended to bypass access controls or disrupt services.
