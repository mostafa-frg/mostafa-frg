Installation and trust boundary. Termux package names were checked against the official Termux package repository metadata on 17 November 2026; that check does not mean the package was installed or runtime-tested on every Android device. Debian/Ubuntu commands target APT-based systems. Fedora, Arch, macOS and native Windows instructions will be added only after separate verification. Review every command before running it. Do not use unknown mirrors or execute unreviewed downloaded scripts.
