Privacy by design. No personal profile data, account, phone, telemetry, browser history, credentials, or private files are needed to use this catalog. The page links to official project sources; it does not execute commands, install software, or upload local data.
Compatibility note. A package being listed does not guarantee every feature works on every operating system or hardware configuration. Windows packet capture may require Npcap; Linux packet operations may require capabilities; macOS applies its own privacy and driver controls. Review the upstream support matrix before installation.
Safe use. Use scanning, web-testing, password-auditing, and forensic utilities only in environments you own or have explicit authorization to assess. Review each upstream license before redistribution.
