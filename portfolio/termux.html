05 / COMPATIBILITY & SECURITY
Know what Android will and won't allow.
Termux is powerful, but it is not identical to a rooted Kali workstation.




WORKS WELL IN USER SPACE
Python, Git, SSH client/server, HTTP tools, DNS utilities, local scripting, file processing, many TCP connect-based diagnostics and offline PCAP parsing.


DEVICE / PERMISSION DEPENDENT
Raw packet capture, monitor mode, packet injection, privileged scans, kernel features, background services and some native binaries. Root, supported chipset/driver, external hardware or a full Linux host may be required.


DO NOT ASSUME ROOT
Root-only packages are separate. PRoot distributions provide user-space environments, not real kernel privilege or wireless driver access.




Source and installation safety
Prefer official Termux app/add-on sources and official package repositories. Do not mix APKs signed by different distribution sources. Treat third-party APT repositories as untrusted until their maintainers, signing keys, build process and package provenance have been reviewed. Use security tools only on systems you own or are authorized to assess.
